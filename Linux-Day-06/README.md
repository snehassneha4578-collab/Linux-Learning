# Linux Day 6 - Directory Management

## Objective
Learn basic Linux commands for creating, navigating, copying, moving, and removing directories.

## Commands Practiced

```bash
mkdir LinuxProjects
cd LinuxProjects
pwd
cd ..
cp -r LinuxProjects LinuxBackup
mv LinuxBackup LinuxFolder
rmdir LinuxFolder
```

## Concepts Learned

- Creating a new directory using `mkdir`
- Changing the current directory using `cd`
- Displaying the current working directory using `pwd`
- Returning to the parent directory using `cd ..`
- Copying a directory using `cp -r`
- Renaming or moving a directory using `mv`
- Removing an empty directory using `rmdir`
